# Mode: always

Run the librarian pipeline automatically before any non-trivial coding, design, or
architecture task — no ledger check, no waiting for the user to ask. Delegate to
`sumbooks-librarian`, then to one `sumbooks-item-reader` per returned angle. Fold the
findings into your plan or answer with inline citations before touching any code.

Best for small projects or short-lived repos where an extra librarian call per task
costs less than the risk of missing a relevant book. For higher task volume, prefer
`smart.md`.
